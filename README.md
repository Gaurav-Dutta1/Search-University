🚀 Activity Showcase
I recently built a mini project where users can search universities by state name 🌍.
 The app fetches real-time data and displays all universities for the entered state.
🔑 Key Tech Stacks:
Frontend: HTML, CSS, JavaScript
API Handling: Axios for HTTP requests & responses
Core Concepts Practiced:
API call & HTTP request-response cycle
DOM Manipulation for dynamic rendering
Event listeners for user interaction
Async/Await & Promises for smooth execution
Error handling with try & catch
Data appending & display
💡 Learning Outcome:
 This project strengthened my understanding of working with APIs, handling asynchronous operations, and building interactive UIs with JavaScript. It was a great hands-on experience in bridging the gap between frontend UI and real-world data.
